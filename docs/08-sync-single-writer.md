# 08 · 同步与唯一写入点

## 8.1 一句话

**两端可写 = 两份真相源。** 一旦 frontmatter 里的关系字段被两边分别改过，谁对谁错没有判据。

所以：选一个目录作为唯一写入口，其他一切都是**单向出口**。

## 8.2 三个通道，各修一个问题

| 通道 | 解决 | 方向 | 冲突策略 |
|---|---|---|---|
| 本地目录（唯一写入口） | 一切 | — | — |
| 云盘镜像 | 多设备**看得见** | 单向：本地 → 云盘 | 只报不改，阻断等人工 |
| Git 仓库 | 历史**回得去** + 烂关系**进不来** | 单向：本地 → 远端 | merge，但钩子先拦校验 |

三者不重叠是很重要的设计。重叠的通道会产生「谁是权威」的歧义，
而歧义一旦出现，人就开始手动解决冲突——手动解决冲突是数据损坏的主要来源。

## 8.3 云盘镜像的三态判定

镜像脚本的核心不是 `cp -r`，而是**判断该不该覆盖**。用三个指纹：

- `l` = 本地指纹
- `c` = 云端指纹
- `s` = 上次一致时的指纹

| 条件 | 判定 | 动作 |
|---|---|---|
| `l == c` | SAME | 什么都不做 |
| 两边都 != s | CONFLICT | **只报不改**，阻断等人工 |
| 只有 `l` 变过 | 推上去 | 单向复制 |
| 只有 `c` 变过 | **阻断** | 不猜、不覆盖 |

最后一行是关键的：云端变了但本地没变，通常意味着有人在手机上改了东西——
而手机上改的那份**可能已经丢了 frontmatter 的关系字段**（多数移动端编辑器会重写文件）。
这时候「猜一下谁新」几乎一定猜错，正确做法是停下来让人看。

首次镜像 `s` 为空，会先报 CONFLICT，需要显式确认一次。**宁可停住也不盖。**

## 8.4 冲突副本：这条路的已知税

云盘并发写会产生副本：iCloud 是 `xxx 2.md`，OneDrive 是 `xxx-副本.md`。

副本一旦进版本库，关系图里就多一张同名卡，而且**不报错**——只是多了个节点。
所以必须由钩子拦（见 [05](05-guardrail.md) §5.2 第一道）。

检测要点：**按 basename 判，不按路径字符串判**。原因见 [09](09-failure-modes.md) F9。

## 8.5 Git：远端是出口，不是第二个编辑器

| 允许 | 禁止 |
|---|---|
| 本地 commit → push | 在网页端直接改文件 |
| 本地 pull 后 merge | 在另一种设备上直接编辑远端 |
| 用 CI 跑校验 | 用 CI 的「自动格式化」改 frontmatter |

禁止网页端编辑的原因很具体：网页提交**绕过 pre-commit**，
于是「进历史的状态都校验过」这个不变量被破坏。破坏一次之后，这个不变量就永远不可信了。

远端存在的意义只有两个：异地备份、历史留存。**它不是协作入口。**

## 8.6 备份不是可选项

云盘 + Git 都不是备份：

- 云盘同步 = 把错误同步到第二个地方（删错了会一起删）
- Git 历史 = 能回滚，但**本机磁盘挂了就全没了**（远端救得回）

**唯一单点仍然是本机磁盘。** 所以：

- 至少一个**离线/异地**副本（外置盘、异地机器、云冷备）
- 定期验证能恢复：`git clone` 到临时目录，跑一遍 `kb.py check`

没验证过恢复的备份，不算备份。

## 8.7 一个可用的最小组合

```bash
# 唯一写入口：~/.kb/vault（Obsidian 打开这个目录）
# 出口 1：云盘只读镜像
python3 tools/sync_icloud.py --mirror        # 三态判定，冲突即停

# 出口 2：Git
bash tools/install-hooks.sh                  # 一次性
git add -A && git commit -m "..."            # 钩子自动跑 check + test
git push
```

这两个出口都是**单向**的。任何人想在云端或远端改内容，都要通过本地目录——
这条纪律比任何技术手段都重要。

## 8.8 验收判据

- [ ] 只有一处目录接受写入，且所有编辑器都打开这同一个目录
- [ ] 云盘镜像在「云端变过」时**停住**而不是覆盖（可以手动造一个改动来测）
- [ ] 冲突副本会被钩子拦下（建一个 `测试 2.md` 提交试试）
- [ ] 远端仓库在网页端禁止直接编辑（或在 README 写明禁止）
- [ ] 存在一个**验证过能恢复**的离线副本
